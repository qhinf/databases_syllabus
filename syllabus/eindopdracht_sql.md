# Eindopdracht 1: SQL

De eerste eindopdracht maak je in {{ Squeek }}. Dit systeem is door de docent
gemaakt. Je vindt er ook veel meer uitleg over SQL.

De score is lineair: hoe meer vragen je goed hebt, hoe hoger je deelcijfer!

**Let op** Squeek bewaart je antwoorden niet, je moet tijdens het werk je bestand
downloaden met de knop bovenaan.
Bovendien is deze applicatie stateless: als je verder wil gaan sleep je het bestand dat je hebt gedownload weer terug.
Het kan zijn dat je computer het document opslaat in je `Downloads`-map. Wees
verstandig, en kopieer het `JSON`-bestand dat de applicatie maakt naar een
mapje met inleverwerk voor deze module.
